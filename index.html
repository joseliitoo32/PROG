Introducción a la Programación Orientada a Objetos

La Programación Orientada a Objetos, conocida como POO, es uno de los paradigmas más utilizados en el desarrollo de software moderno. Su principal objetivo es representar elementos del mundo real mediante clases y objetos. Gracias a este paradigma, el código es más organizado, reutilizable y fácil de mantener.

En Java, todo gira alrededor de las clases y los objetos. Una clase funciona como una plantilla que define atributos y métodos, mientras que los objetos son las instancias reales creadas a partir de esa plantilla.

Ejemplo básico de clase

public class Persona { String nombre; int edad; void saludar(){ System.out.println("Hola"); } }

En este ejemplo la clase Persona tiene dos atributos llamados nombre y edad, además de un método llamado saludar(). Los atributos representan información del objeto y los métodos representan acciones o comportamientos.

Clases y Objetos

Las clases son estructuras que agrupan información y funcionalidades relacionadas. Se utilizan para modelar entidades del mundo real como personas, coches, animales o cuentas bancarias.

Un objeto es una instancia de una clase. Cada objeto tiene sus propios valores para los atributos definidos dentro de la clase.

Creación de objetos

public class Main { public static void main(String[] args){ Persona p1 = new Persona(); p1.nombre = "Jose"; p1.edad = 20; System.out.println(p1.nombre); } }

El operador new se utiliza para reservar memoria y crear un objeto. Después se accede a sus atributos utilizando el operador punto.

Atributos

Los atributos almacenan el estado de los objetos. Normalmente se declaran al principio de la clase y pueden ser de diferentes tipos de datos como enteros, decimales, cadenas de texto o booleanos.

  • int → números enteros
  • double → números decimales
  • String → cadenas de texto
  • boolean → verdadero o falso

Ejemplo de atributos

public class Coche { String marca; String modelo; int velocidad; }

Cada objeto de tipo Coche tendrá su propia marca, modelo y velocidad.

Métodos

Los métodos son funciones que pertenecen a una clase. Se utilizan para definir acciones que pueden realizar los objetos.

Ejemplo de métodos

public class Calculadora { int sumar(int a, int b){ return a + b; } }

Este método recibe dos números enteros y devuelve el resultado de sumarlos.

Constructores

Los constructores son métodos especiales que sirven para inicializar objetos. Tienen el mismo nombre que la clase y no poseen tipo de retorno.

Constructor sin parámetros

public class Persona { String nombre; Persona(){ nombre = "Anónimo"; } }

Constructor con parámetros

public class Persona { String nombre; int edad; Persona(String nombre, int edad){ this.nombre = nombre; this.edad = edad; } }

La palabra this hace referencia al propio objeto y permite diferenciar atributos de variables locales.

Encapsulación

La encapsulación es un principio fundamental de la programación orientada a objetos. Consiste en proteger los datos internos de una clase para evitar modificaciones incorrectas.

Para lograrlo se utilizan atributos privados y métodos getter y setter.

public class Cuenta { private double saldo; public double getSaldo(){ return saldo; } public void ingresar(double cantidad){ if(cantidad > 0){ saldo += cantidad; } } }

Gracias a la encapsulación se evita que el saldo pueda modificarse directamente desde fuera de la clase.

Herencia

La herencia permite crear nuevas clases a partir de otras existentes. La clase que hereda recibe atributos y métodos de la clase padre.

Ejemplo de herencia

public class Animal { public void sonido(){ System.out.println("Sonido genérico"); } } public class Perro extends Animal { public void ladrar(){ System.out.println("Guau"); } }

La clase Perro hereda el método sonido() de la clase Animal.

Polimorfismo

El polimorfismo permite que una referencia de una clase padre pueda almacenar objetos de distintas clases hijas.

Animal a; a = new Perro(); a.sonido();

Aunque la variable sea de tipo Animal, el comportamiento real depende del objeto almacenado.

Interfaces

Las interfaces son contratos que obligan a las clases a implementar determinados métodos. Se utilizan para favorecer el polimorfismo y diseñar programas más flexibles.

public interface Vehiculo { void acelerar(); } public class Coche implements Vehiculo { public void acelerar(){ System.out.println("Acelerando"); } }

Una clase puede implementar varias interfaces al mismo tiempo.

Clases Abstractas

Las clases abstractas sirven como base para otras clases y no pueden instanciarse directamente.

abstract class Figura { abstract double area(); }

Las subclases están obligadas a implementar los métodos abstractos.

Enumerados

Los enumerados permiten limitar los posibles valores de una variable.

public enum Sexo { HOMBRE, MUJER, NO_BINARIO }

Gracias a los enumerados se evita introducir valores incorrectos.
